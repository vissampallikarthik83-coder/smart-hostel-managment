🏨 HostelX – AI-Powered Hostel Management System

HostelX is a smart, AI-powered platform that modernizes hostel management by replacing manual, paper-based processes with a secure, real-time digital system. It connects students, wardens, administrators, and security through role-based dashboards, intelligent automation, and data-driven insights.
🚀 Live Demo:https://hostelmanagement-8f095.web.app

❓ Problem
Traditional hostel management suffers from:
Delayed complaint resolution
Unsafe, manual leave passes
Missed announcements
No transparency or analytics

💡 Solution
HostelX provides a centralized, AI-assisted system that automates hostel workflows, improves communication, and enhances security.

✨ Key Features
🔐 Role-based authentication (Admin, Warden, Student, Security)
🛠️ Digital complaint management with AI prioritization
🚪 Secure OTP-based leave pass & gate verification
📢 Smart announcements with AI refinement
📊 Real-time admin analytics dashboard
🤖 24/7 AI hostel assistant
🌗 Modern, responsive UI with dark & light modes

🛠️ Tech Stack
React • TypeScript • Tailwind CSS • Firebase • Recharts • Vite

🎯 Impact
Faster issue resolution for students
Better visibility and decision-making for admins
Secure and traceable gate management
